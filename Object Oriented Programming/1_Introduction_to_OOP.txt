# INTRODUCTION TO OBJECT-ORIENTED PROGRAMMING

# ============================================================

# 1. WHAT IS OBJECT-ORIENTED PROGRAMMING?

# ============================================================

"""
Object-Oriented Programming (OOP) is a programming approach in
which programs are designed using objects.

An object represents something that contains:

1. Data - information or properties.
2. Behavior - actions that the object can perform.

For example, a Car object can have properties such as:

* Brand
* Color
* Speed

And it can have behaviors such as:

* Start
* Stop
* Accelerate

OOP helps us organize large programs by grouping related data
and functionality together.
"""

# ============================================================

# 2. WHY DOES OOP EXIST?

# ============================================================

"""
As programs become larger, managing all data and functions
individually can become difficult.

OOP was introduced to provide a structured way to organize
complex programs.

Without OOP, a program may contain many separate variables
and functions that are difficult to manage.

With OOP, related data and functions can be grouped together
inside objects.

OOP provides several benefits:

1. Better organization of code.
2. Code reusability.
3. Easier maintenance.
4. Better representation of real-world entities.
5. Easier management of large programs.
   """

# Example without OOP:

vehicle_brand = "Toyota"
vehicle_color = "White"
vehicle_speed = 80

def start_vehicle():
print("Vehicle started.")

def stop_vehicle():
print("Vehicle stopped.")

print("Brand:", vehicle_brand)
print("Color:", vehicle_color)
print("Speed:", vehicle_speed)

start_vehicle()
stop_vehicle()

# ============================================================

# 3. PROCEDURAL PROGRAMMING

# ============================================================

"""
Procedural programming organizes a program mainly around
functions and procedures.

Data and functions are generally handled separately.

For example, a program can store information about a bank
account in separate variables and use separate functions
to perform operations on that data.

Procedural programming works well for small and straightforward
programs.
"""

account_holder = "Ali"
account_balance = 5000

def deposit_money(amount):
global account_balance
account_balance += amount

def withdraw_money(amount):
global account_balance
account_balance -= amount

deposit_money(1000)
withdraw_money(500)

print("Account Holder:", account_holder)
print("Balance:", account_balance)

# ============================================================

# 4. OBJECT-ORIENTED PROGRAMMING

# ============================================================

"""
Object-oriented programming groups related data and behavior
together inside objects.

Instead of keeping account information and account-related
functions separately, we can create an object that contains
both.

This makes the program easier to understand and maintain.
"""

class BankAccount:
def **init**(self, owner, balance):
self.owner = owner
self.balance = balance

```
def deposit(self, amount):
    self.balance += amount

def withdraw(self, amount):
    self.balance -= amount
```

savings_account = BankAccount("Sara", 5000)

savings_account.deposit(1000)
savings_account.withdraw(500)

print("Account Holder:", savings_account.owner)
print("Balance:", savings_account.balance)

# ============================================================

# 5. PROCEDURAL VS OBJECT-ORIENTED PROGRAMMING

# ============================================================

"""
Both procedural programming and object-oriented programming
can solve programming problems.

The main difference is how the program is organized.

Procedural Programming:

* Focuses mainly on functions and procedures.
* Data and functions are often handled separately.
* Suitable for small and straightforward programs.

Object-Oriented Programming:

* Focuses on objects and classes.
* Related data and behavior are grouped together.
* Useful for organizing larger and more complex programs.

Simple comparison:

Procedural:
Data + Functions

Object-Oriented:
Object = Data + Behavior
"""

# Procedural approach

product_name = "Keyboard"
product_price = 2500

def show_product():
print("Product:", product_name)
print("Price:", product_price)

show_product()

# Object-oriented approach

class Product:
def **init**(self, name, price):
self.name = name
self.price = price

```
def display(self):
    print("Product:", self.name)
    print("Price:", self.price)
```

computer_mouse = Product("Computer Mouse", 1800)
computer_mouse.display()

# 6. FOUR PILLARS OF OOP

# ============================================================

"""
Object-Oriented Programming is commonly explained using
four important concepts called the four pillars of OOP.

They are:

1. Encapsulation
2. Abstraction
3. Inheritance
4. Polymorphism

These concepts help programmers design organized,
reusable, and maintainable programs.

We will study each concept in detail in later chapters.
"""

# ============================================================

# 7. ENCAPSULATION

# ============================================================

"""
Encapsulation means combining data and the methods that operate
on that data inside a class.

It also helps control how data can be accessed or modified.

For example, a BankAccount class can contain account information
and the methods used to deposit or withdraw money.

Detailed discussion of encapsulation will come later.
"""

# ============================================================

# 8. ABSTRACTION

# ============================================================

"""
Abstraction means hiding unnecessary implementation details
and exposing only the important features of an object.

For example, when we drive a car, we use the steering wheel,
brake, accelerator, and other controls.

We do not need to know every internal detail of the engine
to drive the car.

Detailed discussion of abstraction will come later.
"""

# ============================================================

# 9. INHERITANCE

# ============================================================

"""
Inheritance allows one class to acquire properties and
behaviors from another class.

For example, a Dog class can inherit common features from
an Animal class.

This helps reduce code duplication and promotes code reuse.

Detailed discussion of inheritance will come later.
"""

# ============================================================

# 10. POLYMORPHISM

# ============================================================

"""
Polymorphism means that the same interface or operation can
behave differently depending on the object using it.

For example, different animals can have a method called
make_sound(), but each animal can implement that method
differently.

Detailed discussion of polymorphism will come later.
"""

# ============================================================

# 11. REAL-WORLD ANALOGY: CAR AS AN OBJECT

# ============================================================

"""
OOP becomes easier to understand when we compare programming
objects with real-world objects.

Consider a Car.

A car has properties:

* Brand
* Model
* Color
* Speed

A car also has behaviors:

* Start
* Stop
* Accelerate
* Brake

In OOP, we can represent a car using a class.

The properties become attributes and the behaviors become
methods.
"""

class Car:
def **init**(self, brand, model, color):
self.brand = brand
self.model = model
self.color = color
self.speed = 0

```
def start_engine(self):
    print(self.brand, self.model, "engine started.")

def accelerate(self, amount):
    self.speed += amount
    print("Current speed:", self.speed)

def brake(self):
    self.speed = 0
    print("Car stopped.")
```

family_car = Car("Honda", "Civic", "Black")

print("Brand:", family_car.brand)
print("Model:", family_car.model)
print("Color:", family_car.color)

family_car.start_engine()
family_car.accelerate(40)
family_car.brake()

# 12. CLASS AND OBJECT

# ============================================================

"""
A class is a blueprint or template used to create objects.

An object is an instance of a class.

For example:

Class:
Car

Objects:
family_car
sports_car
electric_car

Each object can have its own data while sharing the structure
and behavior defined by the class.

We will study classes and objects in detail in the next chapter.
"""

class MobilePhone:
def **init**(self, company, model):
self.company = company
self.model = model

```
def show_details(self):
    print("Company:", self.company)
    print("Model:", self.model)
```

phone_one = MobilePhone("Samsung", "Galaxy A55")
phone_two = MobilePhone("Apple", "iPhone 15")

phone_one.show_details()
phone_two.show_details()
